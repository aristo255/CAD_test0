# CNC Demo — Windows Forms / C#

Демо трёхосевого ЧПУ без подключения к оборудованию. Целевая платформа: Windows, .NET 8 SDK (или Visual Studio 2022 с компонентом «Разработка классических приложений .NET»).

## Запуск в Windows

```powershell
dotnet run --project CncDemo/CncDemo.csproj
```

Или откройте `CncDemo/CncDemo.csproj` в Visual Studio и нажмите F5.

## Возможности

- Координаты XYZ, ручные перемещения с выбираемым шагом, возврат в ноль.
- Редактор и загрузка файлов `.nc`, `.tap`, `.gcode`, `.txt`.
- Проверка G-кода, траектория XY, движение инструмента с заданной подачей.
- Пуск, пауза/продолжение, сброс и аварийная блокировка.
- Пример прямоугольной обработки встроен в редактор.

Поддержаны G0/G1, G21 (мм), G90/G91, F (мм/мин), M2/M30, номера строк N, комментарии `;` и `(…)`. Неподдерживаемые команды вызывают ошибку с номером строки. Пределы: X 0…300, Y 0…200, Z −50…100 мм; G0 — 1500 мм/мин. Каждый новый запуск начинается с X0 Y0 Z0; ручные перемещения не меняют начало программы. «Стоп / сброс» обнуляет координаты, аварийная остановка сохраняет текущие до снятия аварии.

Это учебная модель: без управления реальным станком, шпинделем, коррекции инструмента, ускорений и проверки столкновений. Изображение — проекция XY; Z отображается числом.

## Ручная проверка в Windows

1. «Проверить»: отображается прямоугольная траектория без ошибок.
2. «Пуск»: координаты меняются; «Пауза» останавливает движение, «Пуск» продолжает. Итог: X30 Y30 Z10.
3. Во время движения нажмите «АВАРИЙНЫЙ СТОП»: движение прекращается, пуск заблокирован до снятия аварии.
4. После сброса X− сообщает о выходе за пределы; X+ перемещает ось на выбранный шаг.
5. Введите `G2 X10`: проверка сообщает о неподдерживаемой команде. `G1 X301` сообщает о выходе за пределы.

Сборка в Linux возможна через `dotnet build CncDemo/CncDemo.csproj`; запуск WinForms требует Windows.

Автоматические проверки парсера и ограничений (Windows/Linux):

```sh
dotnet run --project Checks/Checks.csproj
```

## Визуальный конструктор формы

Откройте `CncDemo/CncDemo.csproj` в Visual Studio 2022 и выполните сборку (Ctrl+Shift+B). В обозревателе решений нажмите правой кнопкой на `MainForm.cs` → «Открыть конструктор» (Shift+F7). Можно менять свойства элементов, расположение в контейнерах и назначать события через окно «Свойства». `TableLayoutPanel` и `FlowLayoutPanel` автоматически размещают вложенные элементы: для изменения порядка используйте их коллекцию `Controls`, для размеров — `Dock`, `AutoSize`, `Margin` и стили строк/столбцов.

- `MainForm.cs` — обработчики событий и логика симуляции.
- `MainForm.Designer.cs` — стандартный `InitializeComponent()`, поля элементов и освобождение компонентов; редактируется конструктором.
- `MainForm.resx` — ресурсы формы.
- `TrajectoryCanvas.cs` — панель траектории с двойной буферизацией. Рисование траектории выполняется при запуске приложения.

Проверка открытия и сохранения визуального конструктора требует Windows и Visual Studio; сборка в Linux её не заменяет.
